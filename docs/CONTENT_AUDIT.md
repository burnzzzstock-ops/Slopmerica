Jev doesn't write opinions. It answers typed questions about each line: the probability that a rule is broken, a choice, a score. `COPY_RULES` and `BRAND_RULES` in the script turn those answers into *blocked* and *review*. Change a threshold and rerun, and the report re-sorts from the saved answers in `docs/content-audit.json` without new API calls. This is a screening tool, not legal advice: it points a person at the lines worth a second look.
